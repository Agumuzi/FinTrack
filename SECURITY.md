# Security Policy

## Supported versions

Security fixes are considered for the **latest published FinTrack release**. Older versions may not receive fixes. See [Releases](https://github.com/Agumuzi/FinTrack/releases) for the current version.

## Report a vulnerability privately

Please use [GitHub's private vulnerability reporting](https://github.com/Agumuzi/FinTrack/security/advisories/new) if it is enabled for this repository.

If private reporting is unavailable, [open a non-sensitive issue](https://github.com/Agumuzi/FinTrack/issues/new) to request a confidential contact channel. **Do not put exploit steps, private financial data, account numbers, backup files, credentials, tokens, or sensitive logs in public issues.**

Please include the affected version, macOS version, a description of the impact, and non-sensitive reproduction details. We will review reports as maintainer capacity allows; no fixed response or remediation timeline is guaranteed.

## Scope

Potential application vulnerabilities include unauthorized disclosure of local financial records, insecure handling of API credentials, backup or import vulnerabilities, and update verification problems. Ordinary feature requests and non-security bugs belong in [Issues](https://github.com/Agumuzi/FinTrack/issues).

Financial records and backups are sensitive. Do not upload real user data to demonstrate a vulnerability. This policy does not imply that FinTrack is a security-hardened encrypted vault.
