# 界面截图

产品网站及 README 使用实际 FinTrack v1.3 的 macOS 窗口截图，拍摄于 Apple Silicon Mac。展示统一以 USD 为基准货币。所有账目、名称、资产及计划均为专门准备的虚构示例，与任何真实用户账本无关。

- `overview.png`：概览。
- `records.png`：收支账目。
- `finance.png`：存款及财务计划。
- `exchange.png`：货币与汇率。
- `settings.png`：备份与导出。

示例中的白底黑字“Logo”图片用于说明自定义银行图片功能。用户上传的图片会与银行名称关联保存，再次输入相同名称即可自动匹配，也可复用已有图片。示例图片与这些记录不随应用交付。截图用于产品说明，未对软件界面进行重绘，也不表示素材被另行授予自由再分发许可。
