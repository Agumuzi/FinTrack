# 安装与更新

## 下载和校验

从 [v1.2 Release](https://github.com/Agumuzi/FinTrack/releases/tag/v1.2) 下载 `FinTrack-v1.2-macOS.zip` 和 `SHA256.txt`。需要 macOS 15.0 或更高版本；安装包包含 Apple Silicon 和 Intel 架构。

在下载目录检查：

```sh
shasum -a 256 -c SHA256.txt
```

确认结果为 `OK`，再解压 ZIP，将 `FinTrack.app` 拖入“应用程序”。

## 首次打开

当前包采用 Ad-hoc 签名，没有 Apple Developer ID 签名，也未经过 Apple 公证。首次打开网络下载的应用时，macOS 可能阻止运行。确认下载来源与校验值后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在尝试打开后进入“系统设置 → 隐私与安全性”，为该应用选择“仍要打开”。不同系统版本或管理策略下的提示可能不同。

不需要关闭整个系统的安全保护。若系统报告应用损坏或恶意内容，应停止并核对下载来源。

## 开始使用

首次使用会直接进入内置的空白账本，不预装示例记录。先录入少量数据，退出后重新打开，核对金额与记录；创建一次原生完整备份，妥善保存。大量录入前，应在独立副本中验证恢复能力。

网站截图中的记录均为示例，不随应用交付。

## 安全更新

1. 在旧版中创建完整备份，妥善保存，再完全退出 FinTrack。
2. 从 [GitHub Releases](https://github.com/Agumuzi/FinTrack/releases) 下载目标版本的 ZIP 和同版 `SHA256.txt`，核验后解压。
3. 将新的 `FinTrack.app` 拖入“应用程序”，选择替换旧应用，再打开并核对版本和已有账目。

账本独立保存在本机，替换 `.app` 会沿用已有账本和配置。不要手动删除账本目录或移动运行中的 SQLite 文件。钥匙串 API Key 不随原生账本备份导出。

v1.0 用户需按上述步骤手动替换为当前版本。v1.1 及之后版本内置官方签名更新源：可在“设置 → 关于 FinTrack”中点击“立即检查”，下载经 Ed25519 签名清单和 SHA256 校验的安装包，再确认安装并重启。自动检查可由用户选择开启。应用所在目录必须允许当前用户写入；否则使用 Releases 手动替换。安装前仍建议保存完整账本备份。若应用内下载提示网络失败或超时，可直接使用本页的 Releases 手动下载步骤；确认 ZIP 与同版 SHA256 匹配后再替换应用。

如需降级，请使用升级前对应版本的完整备份；不保证旧版本直接读取新版账本。分类合并与恢复涉及多种本地存储，操作完成前请避免强制退出。

Intel 实机、macOS 15 实机、完整 VoiceOver 及长期真实财务场景尚未完成验证。
