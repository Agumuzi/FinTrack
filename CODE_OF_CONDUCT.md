# Code of Conduct

## Our commitment

FinTrack welcomes feedback, discussions, and contributions from users with different backgrounds, experience levels, and technical skills. We expect respectful, constructive, and efficient communication in issues, pull requests, and code reviews.

## Expected behavior

- Treat others with respect and address facts, designs, and code rather than attacking individuals.
- Provide specific, reproducible, and verifiable feedback and proposals.
- Welcome contributors of different experience levels and respect differences.
- Protect personal privacy and data, and respect code and asset licenses.
- Be open to feedback and focus on resolving problems.

## Unacceptable behavior

Harassment, discrimination, insults, threats, personal attacks, deliberate disruption, disclosing another person's private information (doxxing), and sharing private accounts, financial data, or credentials without authorization are prohibited.

## Scope and enforcement

These rules apply to GitHub issues, pull requests, code reviews, and other project-management discussion spaces. Maintainers may edit or hide inappropriate content, close or lock discussions, and restrict accounts that repeatedly violate these expectations, based on the circumstances.

For harassment or other policy violations on GitHub, use GitHub's built-in **Report content** feature. Non-sensitive maintenance feedback can be submitted as an issue; never publish another person's private information in a public issue. For software vulnerabilities, follow [SECURITY.md](SECURITY.md) and report privately.
